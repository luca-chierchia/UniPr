6. Il sistema informatico entro il sistema informativo

1)Quali sono i componenti principali di un'applicazione?
Risposta: Nelle applicazioni di tipo
interattive(uomo-macchina), i componeneti
principali sono:

 - l'interfaccia utente che permette
 all'uomo di interagire con l'elaboratore.

 - regole funzionali, insieme di funzioni che
 svolgono un determinato compito dopo l'interazione
 con gli utenti.

 - dati, elemento su cui si compie l'elaborazione.

2)Qual'è il ruolo delle reti entro i sistemi
informatici odierni?
Risposta: Le reti sono una componente fondamentale
nei sistemi informatici in quanto permette lo
scambio di informazioni grazie ad un architettura
distribuita, ovvero un insieme di calcolatori che
comunicano tra di loro. (Contrapposte alle
architetture centralizzate, che spesso erano
soluzioni proprietario e quindi presentavano
problemi di compatibilità)

3)Cos'è il modello ISO/OSI che concetto importante
introduce?
L'ISO/OSI(Open System Interconnection) è un
modello concettuale che introduce
la stratificazione e l'idipendenza tra livelli,
descrive come deve avvenire la comunicazione tra
due sistemi in rete ed è suddivisa in 7 livelli:

 1-livello fisico, le strutture che permettono
 il transito dei dati. ( cavi,segnali elettrici/ottici)
 
 2-livello data-link, organizza i bit in frame,
 gestisce errori e accesso al canale.

 3-livello rete, questo livello è responsabile
 dell'instradamento(routing), ad esempio
 protocollo IP.

 4-livello trasporto, ha il compito di suddivide
 i dati in più pacchetti stabilendo l'ordine e
 verificando l'arrivo, il protocollo più utilizzato
 è il TCP ( Transport Control Protocl). Nota i dati
 possono viaggiare anche su percorsi diversi ma
 giunti alla stessa destinazione vengono
 riassemblati con un preciso ordine per essere
 identici come quando sono partiti dalla sorgente.

 5-livello sessione, garantisce un controllo di
 flusso per le informazioni, dal momento che inizia
 fino a quando viene chiusa la comunicazione.

 6- livello presentazione, definisci la corretta
 conversione(codifiche,compressione,cifratura)
 dei dati per renderli comprensibili ai sistemi coinvolti.

 7-livello applicazione: il software che si occupa
 di stabilire la comunicazione tra sorgente e destinatario.




4)Che cos'è il modello client-server? Che
importanza ha entro i sistemi informatici moderni?
Risposta: Il modello client-server è utilizzato
dalle architetture distribuite, dove il server è
un elaboratore che fornisce risorse oppure un
servizio, mentre il client è un altro elaboratore
che richiede tale servizio, talvolta un client può
fungere sia da client che da server, come ad
esempio nei sistemi P2P.
Esistono diverse funzionalità server:

 - File server : computer o servizio di rete che
 mette a disposizione file e cartelle condivise e
 gestisce operazioni di accesso, lettura,
 scrittura e autorizzazione agli utenti della
 rete.

 - Print server: computer o servizio di rete che
   gestisce le code di stampa di più computer
   collegati al print server.
   
 - Domain server, server che gestisce
   utenti,permessi ed autentificazioni in una rete
   aziendale (come Active Directory).
 
 - Database server: elaboratore che ospita e
   gestisce db , salva, legge e scrive i dati ed
   esegue le query.
 
 - Web server: servizio che fornisce pagine e
   servizi web tramite HTTP/HTTPS, è possibile
   accedere alle pagine tramite link, infatti è
   possibile navigare tra gli ipertesti cliccando
   sui link che si trovano incorporati non solo a
   del testo ma anche alle immagini ed i video.
 
 - Terminal server: permette agli utenti di accedere
   a un desktop remoto oppure a delle applicazioni in
   esecuzione su un server, ad esempio è possibile
   utilizzare software non presente sul proprio PC.

 - Groupware server: server che fornisce strumenti
   per lavoro collaborativo.

 - Application server: ospita ed esegue la logica
   applicativa di uno o più programm, fornendo
   servizi complessi tramite API, servi web o
   protocolli specifici.

 - Administration server: è un server dedicato
   alla gestione, configurazione e monitoraggio di
   altri server o servizi all'interno di un
   sistema informativo.

 - Object server: server che espone oggetti
   applicativi accessibili da remoto, permettendo
   ai client di invocare metodi sugli oggetti come
   se fossero locali.

5)In base a quali criteri si procede alla scelta
di un'applicazione entro un sistema informatico?
La scelta del software viene compiuta ad un
livello funzionale, verificando che il software
soddisfi le eseigende del business e supporti
adeguatamente i processi aziendali. A questo
possiamo aggiungere ulteriori criteri, quali:

 - Usabilità e qualità dell'interfaccia utente
 - Compatibilità tecnologica
 - Scalabilità
 - Interoperabilità
 - Costo totale di proprietà
 - Sicurezza

6)Che cosa si intende per interfaccia utente di un
programma applicativo? Quali problematiche sono
legate all'interfaccia utente? Come essa
interviene nel lavoro quotidiano?
L'interfacci utente come ogni componenete
applicativo ha vincoli di compatibilità con le
architetture hardware e software
sottostanti. Infatti un interfaccia utente
possiede un look-and-feel determinato dalle
librerie grafiche e window manager di sistema.

7)Che cosa sono le matrici di compatibilità del
software?
Una matrice di compatibilità è una tabella che
mette in relazione un software con i possibili
ambienti di esecuzione (OS, browser, hardware,
librerie) indicandone compatibilità, versioni
supportate e limitazioni. Serve a garantire
portabilità e corretto funzionamento all’interno
del sistema informatico.

9)Che cosa si intende "problemi di manutenibilità
di un software?
La manutenibilità del software è uno dei maggiori
dei problemi dei produttori di applicativi, questo
è la fase che segue l'entrata in servizio di un
software. Si possno distinguere :

- Manutenzione evolutiva: cambiamenti del software
  per adattamenti a nuove specifiche.

- Manutenzione ordinaria: correzzione errori che
  non dovevano essere presenti in fase di rilascio.

10)Che cos'è un sistema informatico distribuito?
In che situazioni esso si trova? Quali
problematiche di gestione vi sono associate?
Un sistema informatico distribuito è un sistema
che opera tra 2 o più nodi(computer) collegati in rete,
in genere questi modelli si definiscono
client-server oppure modelli multi-tier. Il
modello client-server presenta problemi di
scalabilità, complessità e supportabilità, infatti
sono spesso presenti all'interno di piccole
aziende oppure dipartimenti aziendali.

11)Che cosa si intende per business continuity?
La business continuity è la capacità di un sistema
informatico di garantire continuità di servizio,
talvolta viene anche utilizzato il termine
24x7x365.


12)Che cosa sono i configuration item di ITIL?
I configuration item sono tutti gli elementi  che
contribuiscono al funzionamento ed alla business
continuity di un sistema, tra essi possiamo
trovare: l'hardware del PC, i vari tipi di
software, server, componenti di rete,
documentazione, procedure, servizi IT, altri
servizi business, etc.

13)Che cos'è la catena delle dipendeza attraverso
gli strati dell'architettura TOGAF?
La mappatura precisa delle dipendenze del livello
business dai livelli applicativi che a loro volta
dipendono dal livello tecnologico (infrastruttura
IT), ci permette di stabilire graficamente quali
elementi sono dipendono da altri, in questo modo
si possono prendere decisioni mirate su che cosa
intervenire in caso di migliorie del sistema.

Alcune osservazioni utili

Nella progettazione di un sistema informatico
moderno è essenziale comprendere come i diversi
componenti dell’architettura interagiscono tra
loro per garantire scalabilità, affidabilità e
flessibilità. Concetti come l’architettura
distribuita client–server, i diversi tipi di
server (Web Server, Database Server, Object
Server, Transaction Server, Domain Server, ecc.) e
gli standard architetturali (come l’ISO 42010)
permettono di strutturare il sistema in entità
logiche specializzate

Tabella degli esempi di Server

| **Tipo di Server**        | **Funzione principale**                             | **Esempi concreti (software / tecnologie)**                     |
| ------------------------- | --------------------------------------------------- | --------------------------------------------------------------- |
| **File Server**           | Condivisione file e cartelle, gestione permessi     | SMB (Windows Server), NFS (Linux), Samba, NAS Synology/QNAP     |
| **Print Server**          | Gestione code di stampa e stampanti di rete         | CUPS (Linux), Windows Print Server, PaperCut                    |
| **Domain Server**         | Autenticazione centralizzata, permessi, domini      | Active Directory (Windows), OpenLDAP, FreeIPA                   |
| **Web Server**            | Fornisce pagine web e API via HTTP/HTTPS            | Apache, Nginx, IIS, LiteSpeed                                   |
| **Database Server**       | Gestione dati, query, transazioni                   | MySQL, PostgreSQL, Oracle DB, SQL Server, MongoDB               |
| **Groupware Server**      | Strumenti collaborativi: email, calendari, chat     | Microsoft Exchange, Zimbra, Google Workspace, Lotus Domino      |
| **Transaction Server**    | Gestione transazioni ACID e integrità dei dati      | CICS (IBM), Tuxedo (Oracle), transaction managers di Java EE    |
| **Object Server**         | Espone oggetti/metodi remoti via rete               | CORBA ORB, Java RMI Server, DCOM, EJB container (JBoss/WildFly) |
| **Application Server**    | Esegue logica applicativa (API, servizi business)   | WildFly/JBoss, WebLogic, GlassFish, Tomcat*, Node.js, .NET Core |
| **Administration Server** | Gestione, monitoraggio e configurazione dei sistemi | Windows Admin Center, Cockpit (Linux), Nagios, Zabbix, vCenter  |
