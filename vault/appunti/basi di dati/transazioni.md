# Transazioni
#transazioni, #basi-di-dati, 

==Una transazione identifica un'unita elementare (sequenza di azioni atomiche che devono essere eseguite interamente) di lavoro svolto da un applicazione==, a cui associamo le proprietà [[ACID]],.

Un sistema che mette a disposizione un meccanismo per la definizione ed esecuzioni di transazioni viene detto sistema transazionale.
